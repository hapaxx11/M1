**Sub-GHz: automotive keyfob signatures in Signal ID (RF Rosetta)** — The fingerprint database now carries per-protocol signatures for the 24 ProtoPirate automotive decoder families (Honda, Ford, Kia, Fiat, Renault, Mazda, Subaru, Chrysler, PSA, VAG) with bands, modulation, timing windows, bit ranges, and rolling-code security metadata drawn from the corrected protocol-registry timings. Each signature links to its registry decoder (new `registry_index` field) for future decode hand-off. Signal ID now names these protocols specifically instead of misclassifying them: Subaru and Kia V1 were labeled garage/weather, Honda V1 as weather, Renault V0 missed the fob floor, and Ford V1 was identified as a TPMS tyre sensor. Specific signatures outrank the generic "Car Key Fob" catch-alls, which still match unknown fobs. Host tests verify window/band/mod consistency with the registry and the specific-before-generic ordering.

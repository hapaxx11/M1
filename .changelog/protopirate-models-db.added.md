**Sub-GHz: ProtoPirate models database** — The Proto Pirate menu gains a "Models DB" scene: a bounded, host-tested parser for the upstream v2 car-models database reads `SubGHz/models_db/models.txt` from the SD card and lists receiver presets (name + frequency + modulation). Selecting an entry applies the frequency and modulation and opens the Read scene with the ProtoPirate filter. Flipper preset names map to M1's SI4463 AM/FM presets; the published Honda `FuriHalSubGhzPresetCustom` CC1101 register blob is acknowledged but never consumed — it maps to M1's FM476 preset instead. Entries with unknown presets or out-of-range frequencies are skipped; a missing or invalid database shows an install hint. The upstream database ships in the repo at `subghz_database/models_db/models.txt` with attribution in `SOURCES.md`. 20 host tests cover parsing, mapping, truncation, and malformed inputs.

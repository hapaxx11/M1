**Sub-GHz: Remote Analyzer scene** — The Proto Pirate menu gains a Remote Analyzer: an asynchronous SI4463 scene that two-stage sweeps for a signal's frequency (6 region-aware hopper frequencies coarse, then ±300 kHz @ 20 kHz fine), reports frequency/RSSI/modulation (AM classified by a steep >6 dB neighbor drop at the fine peak), smooths the reading with an adaptive filter, and holds the last reading briefly when the signal drops. OK pauses/resumes the sweep; LEFT/RIGHT adjust the trigger level (−110…−60 dBm). The detection logic is a pure host-tested module (23 tests) derived from ProtoPirate's detection concepts without the CC1101 register worker; the scene shares the Timing Tuner's radio lifecycle with instant BACK cancellation. On-device detection validation is still outstanding.

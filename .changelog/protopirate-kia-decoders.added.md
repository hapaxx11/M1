**Sub-GHz: ProtoPirate Kia RX decoders** — Replaced the Kia V0, V1, V2, V3/V4, V5, and V7 name-only placeholders with real frame parsers and waveform decoders. Kia V0 covers the Kia/Suzuki/Honda V0/Mitsubishi sub-types with the sub-type persisted via the upstream-compatible `Type:` field; V3/V4 share one core with polarity-filtered wrappers and KeeLoq manufacturer-key (keystore Type 10) validation, committing structurally with zeroed fields when no key is provisioned; V5 recovers the counter through the Type 13 mixer key when available; V7 keeps the complemented-word CRC-8 gate. The build-time keystore generator now accepts any subset of Kia key types 10–13. Corrected the Kia registry entries (315/433 MHz, upstream AM/FM, V3/V4 68-bit minimum) and removed inappropriate generic OOK-PWM replay flags. Aligned the Kia TX encoders with the upstream wire formats: V0 symmetric PWM pairs with CRC-8 poly 0x7F and proper frame terminators, V3/V4 direct manufacturer-key encryption (no simple learning), V5 built-in-key fallback, V7 Manchester pair emission with the saved-candidate field layout and 15-pair tail pass, and V1/V2 key-only counter fallbacks matching the committed key layout. The capture pipeline now keeps undecoded buffers open across 1.5–5 ms gaps so long-symbol frames (Kia V1, Honda V1, Ford V0 mid-frame gap) accumulate instead of splitting at every long pulse, the capture buffer grew to 1280 pulses for gapless Kia V2 uploads, and Kia V1/V2 frames reconstructed through hidden-pair recovery require a valid CRC-4 to commit, dropping tail-truncated phantom decodes. Host-tested with synthetic positive/negative waveform suites; on-device RF validation not yet performed.
